## Gotchas for this machine

- Never "Reset to factory defaults" in Docker Desktop — it wipes every project's volumes. If
  it fails to start with `initializing Inference manager … dockerInference`, stop Docker
  Desktop and rename `%LOCALAPPDATA%\Docker\run` to `run.stale-<date>`.
- Disk fills from Docker's vhdx: `docker builder prune -af`, then a graceful
  `docker desktop stop` compacts it.
- uv `[tool.uv.sources]` apply only to direct dependencies — anything torch-related must be
  listed directly in `services/worker/pyproject.toml` or Linux gets the CUDA wheel.
- Never run two DB-backed pytest sessions at once (shared `physicalai_test` → deadlocks).
- Regenerate contracts with the CI env vars set (see `.github/workflows/ci.yml`), then
  `npm run generate && npm run build` in `packages/contracts`.
