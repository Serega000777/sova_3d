## Записка: что осталось и что не успел

Из запроса «сделать как у KIRI Engine и Polycam, но лучше» (разбор — `docs/COMPETITOR_UI_ANALYSIS.md`):

**Не сделано вообще**
- Выбор метода и качества **до обработки скана** (фотограмметрия / гауссовы сплаты, качество, размер текстуры,
  «изолировать объект»): конвейер реконструкции этого не принимает (`FinalizeBody` — только масштаб).
  Нужны: децимация и размер текстуры в воркере, метод сплатов, маскирование объекта. Реестр
  (`QUALITY_PRESETS`, `TEXTURE_SIZES`, `ProcessingOptions`, `METHOD_COMPARISON`) уже готов в контрактах.
- Самообучение моделей: **ничего не обучается**. Есть честный план — `docs/SELF_LEARNING_PLAN.md`
  (флаг согласия, кнопки оценки, датасет, оценка до выкладки). Первым делом шаги 1–2.
- Экран результата скана с колонкой действий (пустая комната, тема, измерение, план, правка) и «Экспорт» снизу.
- Экран «Исследовать» (лента сообщества по типам), видеопомощь, превью-картинки в библиотеке и карточках.
- Прогресс-окно обработки с «Отмена» и уведомление о готовности.
- Подготовка со съёмкой: картинки и анимации в шагах (сейчас только текст), режим «Захват сцены».
- Видео с устройства (из галереи фото уже можно: кнопка «Из галереи» в съёмке, без позы камеры; на телефоне не проверено, только сборка и API-тест).
- Режим съёмки AR/ручной экспозиции на mobile.

**Сделано частично**
- Создание: сценарии есть на web/desktop/mobile, но desktop — это та же web-оболочка (отдельной проверки в Tauri не было);
  на mobile нет сценариев «План этажа» и «3D-файл» (нет экранов).
- Библиотека: нет миниатюр моделей (в API нет превью-картинки проекта).
- Дом из комнат: только геометрия на `/plan`; реальные сканы RoomPlan (T-197) и проверка T-196 на LiDAR-iPhone не сделаны.

**Прочий остаток (из прошлых блоков)**
- T-235/T-236: точные операции ядра для параметрических тел; панель правки на desktop/mobile.
- T-237: план из результата RoomPlan и из фото; T-238: общие аннотации через API, фото к замечанию, переход в 3D.
- T-233: многовидовая реконструкция здания снаружи.
- Нужно от владельца: сборка EAS и проверка RoomPlan на iPhone с LiDAR (Swift ни разу не компилировался).
